# URL inventory, November 2026 (NRD-22)

SEO method phase 1 (epic NRD-4). Measured inventory of every URL in the sitemap: intended target query, title, H1, indexation state, cannibalization, thin pages and orphan pages. Inputs for phase 2 (NRD-73, keywords) and phase 3 (NRD-74, page rewrites). This document records observations and recommendations only; no page, copy, URL, redirect or link was changed.

## Method and data windows

- **On-page columns** (measured, reproducible): `pnpm build && pnpm seo:inventory` reads `dist/sitemap-0.xml` and each built `index.html`, and classifies each URL with `keywordOwners`, `intentMatrix`, `nicheRoutes` and `serviceRoutes` from `src/data/seo-intents.ts`. Build of develop at commit `4a17578`, run on 2026-11-15. 24 URLs.
  - Word count and inbound links are measured on the content of `<main>` only (scripts and styles excluded). "Inbound" is the number of other pages whose `<main>` links to the URL, so header and footer links do not count; self links are ignored; query and fragment are dropped.
  - Status order: `parked` (`nicheRoutes` and `/seo-para-clinicas-capilares-sevilla/`), `legal`, `in-focus` (`/` and the remaining `serviceRoutes`), else `support`. Target query is the `keywordOwners` keyword(s) owning the URL, else the `intentMatrix` topic, else `none`.
- **Search Console** (property `sc-domain:nuriaromero.dev`, read-only service account):
  - Queries: `gsc_query`, dimensions `page,query`, web search, country ESP, all devices. **Window returned by the API: 2026-10-16 to 2026-11-12 (28 days)**, exported on 2026-11-15 (the last 2-3 days are not consolidated, so the window ends on 2026-11-12). The API returned 69 page-query rows and totals of 1,156 impressions, 2 clicks. Search Console omits anonymised queries, so the 69 rows do not add up to the total and every row shows 0 clicks: the two clicks belong to queries that Google does not export. All figures below are for this window only.
  - Indexation: `gsc_inspect` (URL Inspection API) on each of the 24 URLs, captured 2026-11-15. The state is Google's view at that date, not at the end of the query window.
  - Raw exports were saved outside the repository and are not committed.
- **N/D** means not available. "N/D: sin impresiones" means the URL had no impressions in the window (its coverage state is still recorded).
- Competitor evidence used later comes from `.claude/state/seo/2026-11-13.md` (DataForSEO and public web, 2026-11-13); that file is not part of the repository.

## Cannibalization

Method: `findCannibalization` (`scripts/lib/seo-inventory.mjs`) over the 69 page-query rows of the window 2026-10-16 to 2026-11-12 (web, Spain, all devices). It keeps queries (exact string) for which two or more distinct URLs have impressions. Variants of one head term that sit on the same URL (for example "diseño paginas web sevilla", "diseño de paginas web sevilla" and "diseño de páginas web sevilla" on `/diseno-web-sevilla/`) are not cannibalization. Positions are the average position Search Console reports for that page and query in the window; no clicks were reported on these rows.

Result: 2 of the queries have two URLs. Owners come from `keywordOwners` (ADR 0012) and the PRD (home: "consultor SEO en Sevilla"; `/seo-local-sevilla/`: "SEO local Sevilla" and the NRD-33 head terms "agencia seo sevilla" and "posicionamiento web sevilla").

### Cases that did not occur in this window

- "seo local sevilla" (owner `/seo-local-sevilla/`): 76 impressions at position 32.5 on the owner and no impressions on `/`. The case "owner ranks behind another page" is not present, so no re-target is needed for the head terms.
- "consultor seo sevilla" (owner `/`): 3 impressions at position 6.3, only on `/`.
- "agencia seo sevilla", "posicionamiento web sevilla" (owner `/seo-local-sevilla/`) and "diseño tienda online sevilla" (owner `/tienda-online-sevilla/`) have no impressions on any URL in the window. The owner of the last one is `Discovered - currently not indexed` (see the coverage table).

### Limits

- Exact-query matching only; near-duplicates such as "seo local en sevilla" and "seo local sevilla" are both on `/seo-local-sevilla/`.
- Anonymised queries are not exported by Search Console (the 2 clicks in the totals are not in the rows), so a cannibalization on low-volume queries can be hidden.
- One 28-day window with 1,156 impressions in total: every conclusion is directional, not statistical.
