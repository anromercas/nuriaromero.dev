# 0013. SEO site architecture: one owner page per keyword cluster

- Status: Proposed (the PO sets it to Accepted when accepting NRD-74; each radical proposal stays "Pendiente de la usuaria" until the user approves it in the PRD decision log)
- Date: 2026-11-15

## Context

SEO method phase 3 of 8 (epic NRD-4, story NRD-74). The user's first SEO priority is keyword targeting of the service pages, and reworking the structure if it is wrong, before any page rewrite (phase 5, NRD-76) or link building (phase 7, NRD-72). NRD-22 measured the 24 URLs, NRD-73 and NRD-97 grouped the Seville queries of six services into clusters, NRD-98 diagnosed indexation. This ADR turns those inputs into one decision: which page owns which cluster, what each existing page is (keep, re-target, merge, split, create), how the pages link to each other, which URL changes follow, and in what order phase 5 should work.

The ADR names changes; it never applies them. No `src/**`, `public/**`, test or script file changes in this story. Ownership of a term keeps the rule of ADR 0012: one owner page per head term, and only the owner targets it in `<title>`, H1 or H2.

Conventions: analysis in English, queries and page copy in Spanish verbatim. **Dato observado** is a figure with its source and date; **Inferencia** is a reading of those facts. "gap" means not measured and "sin dato (...)" means the tool returned no value; neither is 0 and no figure here is estimated. Source ids S1 to S10 are those of `docs/seo-audit/keyword-clusters-2026-11.md` ("Fuentes reutilizadas"). Volumes are Spain-level monthly searches; Search Console figures are impressions and average position in the single 28-day window 2026-10-16 to 2026-11-12 (web, Spain, all devices), so every conclusion is directional.

## Decision

One owner page per in-focus keyword cluster, mapped below. The decision is **adjust**, not rework (verdict line and reasons below). Three kinds of statement are kept apart:

- **decided**: the owner is an existing URL that fits the evidence; the per-page story can start.
- **provisional**: the owner is proposed and still stands, but one named input is weak or missing; the per-page story re-checks that input first.
- **pending the user**: creating a page or a service is radical (PRD section 9); the row is a proposal with options and a recommendation in "Propuestas pendientes de la usuaria" and nothing is applied until the user approves it in the PRD decision log.
