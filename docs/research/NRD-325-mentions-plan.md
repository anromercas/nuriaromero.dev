## 5. Tactics

Three tactics, each a hypothesis to test, not a promise. None involves payment, link exchange, guaranteed placement, fake reviews or invented partners. Efforts are the owner's time, counting only writing and sending; replies are outside her control. Measurement uses the same recorded sources as section 2 so the before and after are comparable.

### Tactic A: get listed in the third-party lists that already answer the head term

- Description: ask for inclusion in the existing lists and directories that rank or are cited for `agencia seo sevilla` (SEO report 2026-11-21: the AI Overview cites `ip10.es` and `pacoruben.com`; page 1 holds `webdemarketing.net`, `sergidoseo.com` and others), using `/seo-local-sevilla/` and `/sobre-mi/` as the verifiable identity. Owner mentions only real facts, offers nothing in exchange, and drops a list that asks for payment or a link back.
- Targets used: ranks 5, 6, 7, 8, 16, 17 (section 4).
- Effort: S per target (about 30 minutes each to read the inclusion route and write one message); 6 targets, about 3 hours in total. Some routes are not verified (ranks 6 to 8, 17).
- Expected return (hypothesis): if one or two of these lists add a mention of Nuria Romero or `nuriaromero.dev`, the lists the AI Overview cites would name her, which is the gap seen on 2026-11-21 (absent from local pack, AI Overview and top 10). It would confirm if a later `ai_opt_llm_ment_cross_agg_metrics` call shows mentions where there were none, or the list page names her. It would be refuted if no list accepts after 60 days or if all inclusion routes are paid. No ranking is promised.
- How to measure: at day 30 and day 60, a data step of the SEO strategist with `backlinks_bulk_referring_domains` (referring domains), `ai_opt_llm_ment_cross_agg_metrics` (Google, Spain, `es`) and one `serp_organic_live_advanced` read of `agencia seo sevilla` at `Seville,Andalusia,Spain`; plus a public GET of each list page to see whether the entry exists. Baseline: 38 referring domains, no mentions (2026-11-21).
- Risks: IP10 is a competing agency (owner decision, as in NRD-21); lists can be pay-to-play (discard); a mention on a list may be `nofollow` (still a mention for AI answers, not a link signal); counts have day-to-day noise, so read only trends.

### Tactic B: local institutions and developer communities as a source of resource links and talks

- Description: start with the 5 verified opportunities in NRD-72 (Cámara de Comercio TIC Negocios guides, Sevilla Emprendedora, WordPress Sevilla, WordCamp Sevilla 2027, GDG Sevilla) using the register's allowed script ("He publicado este recurso porque explica [tema]..."), then add Fullstack Sevilla and the chamber's TIC Negocios portal.
