# social-video-template

## Objective

A reusable vertical video template (1080 x 1920, 30 fps) for the social module, built on HyperFrames and rendered by one command from a JSON data file in the piece folder, so it can be wired as `social.production.videoCommand`.

## Problem and why

The carousel template exists (`social/plantillas/carrusel`), but faceless video pieces have no renderer. The owner wants text-on-screen videos without voice, animated comic strips and simple stick-figure scenes, with royalty-free music embedded in the file so it plays on every network.

## Scope

- In: `social/plantillas/video/` (render script, timing module, README, music generator), three scene types (`text`, `panel`, `puppet`) plus an end card, embedded music with fade in/out, three demo renders in the session scratchpad.
- Out: voice-over, captions from audio, writing into `social/piezas/*`, wiring the command into `.claude/harness.json` (owner decision), committing (the `social/` folder is untracked).

## Constraints

- Owner decisions 2026-11-20: no voice-over; music embedded in the video file; the track must allow commercial use and be credited (track, author, source, licence). Never copyrighted commercial music.
- Brand from `social/plantillas/carrusel` (tokens, Onest + Instrument Serif, one italic emphasis per headline).
- Safe zones for TikTok/Instagram UI: no text in the bottom 20 % (y > 1536) nor in the right 140 px strip.
- On-screen texts copied verbatim from the piece sources.
- TDD: strict (source: user global config). Runner for the template's pure logic: `node --test social/plantillas/video/*.test.mjs` (the repo's `tests/` runner covers tracked site code only; this folder is untracked).

## Acceptance criteria

- One command renders a piece: `node social/plantillas/video/render.mjs {piece}/video.json` -> `{piece}/export/video.mp4`, 1080 x 1920, 30 fps, H.264 + AAC audio.
- The three scene types and the end card render with the brand look; texts stay inside the safe zones.
- Music fades in and out; credits written next to the export.
